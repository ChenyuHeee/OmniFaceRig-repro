## 0. 一句话总结

输入**一个只有外表面、没有口腔建模的静态 3D 角色网格**(任意拓扑:人/人形/长吻/短吻动物),全自动输出**生产级 FACS 表情 rig(最多 155 个 blendshapes)+ 程序化生成的牙齿/牙龈/舌头 + 重打包 UV/贴图**,无需任何手工标注、模板或逐资产配置。

## 1. 关键贡献

1. **全自动端到端**人脸 auto-rigging pipeline(无手工 landmark、无口腔摆放、无逐资产模板)。
2. **口腔感知的 rig 构建**:程序化生成输入中不存在的牙齿/牙龈/舌头/口腔支撑几何,并用 **ARAP + SDF** 拟合与碰撞消除,与 FACS blendshape 转移集成。
3. **Omni-Bench 数据集**:1,000 个双足 T-pose 角色(带 FACS blendshape + 口腔几何),含生成链路全数据(文本 prompt、2D 参考图、AssetGen2 生成的 3D mesh)。
4. **跨非人拓扑泛化**:长吻动物(狗/狼/狐狸)、短吻动物(猫/熊/兔/虎),靠 3 个拓扑模板 + **无鼻子 landmark 设计** + ARAP+SDF 牙齿摆放,同一 pipeline 不换架构。

## 2. Pipeline 总览(两阶段)

**Stage 1 — Face Template Fitting(§3.2–§3.5)**
正面渲染 3D mesh → 人脸检测裁剪 → 多模型分割 ensemble → **VLM+CV 混合 riggability 评估**(决定做不做 + 选模板配置)→ 2D/3D 关键点提取 → 刚体 + 非刚体模板配准,得到贴合输入脸的拟合网格。

**Stage 2 — Blendshape Rig Construction(§3.6)**
拟合模板 → 人脸网格融合(替换原脸)→ 程序化生成并摆放口腔几何(牙齿/牙龈/舌头)→ 重打包 UV 烘焙贴图 → 从规范 rigged 模板转移 FACS blendshape。

```
输入静态mesh ──渲染──> 正面图 ──检测/裁剪──> 脸区域图
    │                                            │
    │                              ┌─ 人脸landmark(68点)
    │                              ├─ Sapiens(基础人体parser)
    │                              ├─ SAM 3(零样本分割)
    │                              └─ 微调Sapiens(41类stylized / 38类humanoid)
    │                                            │ 逐区域自适应选最优
    │                              ┌─ VLM语义检查(Q1-Q3,Q6-Q8)
    │                              ├─ 分割掩码几何检查(Q5,Q9,Q10)
    │                              └─ 嘴部landmark质量门(Q4, 三路投票)
    │                                            │
    │                              2D/3D关键点(掩码轮廓+射线反投影)
    │                                            │
    │                              Stage1: 刚体对齐(式1)
    │                              Stage2: 非刚体形变(式2, 6项能量)
    │                                            ↓ 拟合模板
    └──────────────> Stage 2: 脸融合(凸包布尔+焊接) / 口腔生成(RBF+ARAP+SDF)
                     / UV重打包 / FACS稀疏变形迁移 → 最终rig(最多155 shapes)
```

## 3. 模块详解

### 3.1 Riggability 评估(§3.2)— 三信号融合

用**一张正面渲染图**,融合三个信号:
- **VLM 语义信号**:判断角色原型(human/humanoid/feline/canine/other)、遮挡(眼镜/护目镜/面具/眼罩)、牙齿状态(张嘴/闭嘴/表情)。VLM 两职责:① 过滤不可 rig 资产(无脸、严重遮挡、喙/怪拓扑);② 选择下游配置 —— 人脸模板变体(human/long-muzzle/short-muzzle)+ 口腔原型(human/canine/monster/flat)。
- **CV 分割掩码信号**:face/eye/mouth 掩码的几何合理性检查(存在性、包含关系、眼-头面积比、唇封曲率)。
- **Landmark 质量信号(仅人类脸)**:用 `CVlip`(唇轮廓 landmark 间距的变异系数)做质量门 —— 超过阈值则判定 landmark 不可靠,不参与投票。非人资产直接丢弃 landmark 信号。

**问题分配表(Table 4)**:

| Q# | 检查项 | 信号源 |
|---|---|---|
| Q1 | 脸类型(人/动物/其他) | VLM |
| Q2 | 可见脸数量 | VLM |
| Q3 | 可见眼眶数量 | VLM |
| Q4 | 嘴存在且可定位 | **多数投票**(VLM+分割+landmark) |
| Q5 | 眼部遮挡 | 分割掩码 |
| Q6 | 眼饰遮挡 | VLM |
| Q7 | 嘴状态 | VLM |
| Q8 | 牙齿可见性 | VLM |
| Q9 | 眼-头面积比 | 分割掩码 |
| Q10 | 唇封曲率 | 分割掩码 |

融合逻辑:Q1–Q3、Q6–Q8 直接取 VLM;Q5/Q9/Q10 取分割检查;Q4 人类脸走三路多数投票(landmark 不可靠则降级为 VLM+分割),非人脸走 VLM+分割 与(conjunction)。最终决策 = 所有问题结果的与。

**效果(Table 3,~500 资产验证集)**:VLM only 94.7% F1;CV only 80.9% F1;**VLM+CV >95%**。剩余失败模式:标注边界歧义 + VLM 对眼镜/嘴态/牙齿的误判。

### 3.2 分割模型(§3.3)— Sapiens 微调

- 骨干:**Sapiens-1B**(高分辨率 ViT,masked reconstruction 预训练)。预训练语料 ~4B 真实人像;先 512×512 再切 1024×1024;中间在 **20M 风格化角色图**上无监督域适应(带来 2–3% 提升)。
- 微调:冻结 ViT,只训一个轻量**三阶段反卷积解码头**。两个共享编码器的 checkpoint:
  - **41 类 stylized parser**(人类/类人,细分眉毛/眼/耳/唇/牙齿/舌头/头发/眼镜/遮挡物)
  - **38 类 humanoid parser**(卡通动物/强非人角色)
- 训练:~10k 标注 2D 图(人/人形/猫/犬/熊等,正面 T-pose 渲染);AdamW lr=1e-4,cosine decay + 500 warmup,batch 16,**50 epochs,8×A100,~24h**;增强:水平翻转/颜色抖动/±15° 旋转/0.8–1.2 缩放;类别平衡交叉熵。
- 结果:微调后 mIoU **87.3%**(原始 Sapiens 62.1%);猫脸 31.2%→84.5%,狗脸 28.7%→81.9%,人脸 89.1%→91.2%。
- 部署形式:JSON 标签配置 + **TorchScript** checkpoint,轻量 train–export–infer 栈。

### 3.3 检测与分割 ensemble(§3.4)— 4 模型并行 + 逐区域选择

| 模型 | 特点 |
|---|---|
| 人脸 landmark 检测(68 点) | 人类/近人脸上高精度,动物上几乎失效 |
| Sapiens 基础 parser | 人鼻/唇/皮肤强,强非人脸退化 |
| SAM 3 | 类无关零样本,风格化/非人脸泛化好,但边界粗糙 |
| 微调 Sapiens(41/38 类) | 动物上大幅提升,人上保持 |

选择策略:人类→landmark(眼/嘴)+ Sapiens(鼻/皮肤);风格化人形→41 类微调 Sapiens;动物→38 类微调 Sapiens 为主 + SAM 3 兜底脸边界;**逐区域自动回退**。

**消融(Table 10,检测召回率)**:landmark 单独 41% / Sapiens 55% / SAM 3 72% / 微调 Sapiens 88% / **4 模型 ensemble ~99%**(人类 100%、猫 100%、狗 97%)。

关键点提取:2D 关键点(脸边界/眼/鼻或吻部/嘴)从掩码轮廓 + landmark 读出;每个 2D 点**沿渲染相机射线反投影**与 mesh 求交得到 3D 位置 → 2D+3D 对应作为配准输入。

### 3.4 模板配准(§3.5)

**模板库**:3 个 quad-mesh 模板 —— human(平脸/下巴/眼嘴共面)、long-muzzle(长吻:狗/狼/狐/马)、short-muzzle(短吻:猫/熊/兔/虎),由 VLM 自动选。

三个设计原则:
1. **无鼻子 landmark**:锚点只在掩码边界均匀采样;鼻子掩码在动物/风格化人形上既不准又不稳,干脆排除,鼻子位置交给优化本身(由边界/眼/嘴锚点引导)。消融:带鼻子锚点时 78% 动物资产鼻子-嘴区域严重畸变 + 10% 崩溃;去掉后 **0% 崩溃**。
2. **拟合拓扑与动画拓扑解耦**:拟合模板(为关键点对应优化)与动画拓扑(眼/嘴周围径向 edge loop,肌肉方向形变)是两个网格,靠 UV 对应链接,可独立改。
3. **最小区域拟合**:模板只贴到面部特征凸包,不延伸到脖子/下巴 → 更贴合、边界伪影少、对盔甲/围巾/长下巴鲁棒。

**两阶段优化**:
- Stage 1 刚体对齐:min Σᵢ ‖sR·vᵢ + t − pᵢ‖²(式 1,求 R/s/t)。
- Stage 2 逐顶点非刚体形变(式 2):
  `E(D) = λ₁E_corr + λ₂E_smooth + λ₃E_edge + λ₄E_tri + λ₅E_flip + λ₆E_reg`
  - E_corr:对应项,Huber 鲁棒惩罚忽略离群点
  - E_smooth:邻接顶点位移差 L2(平滑)
  - E_edge:边保持(局部刚体)
  - E_tri:三角形形状矩阵保持(防瘦长/剪切)
  - E_flip:**法向翻转惩罚 max(0, −n·n′)³**(防翻面/自交)
  - E_reg:位移 L2 正则
- 归一化网格上对齐误差 <1e-5;动物资产**零崩溃**。

**三种关键点回退机制**(保证零无效关键点):
1. 边界关键点的网格表面回退(掩码边界纠正后仍无 3D 位置 → 找 mesh 表面最近像素);
2. 3D 锚点回退(2D→3D 投影失败时用已解出的邻接锚点 3D 位置推算);
3. 自适应眼掩码选择(人用 landmark 眼、动物用分割眼,自动回退)。

### 3.5 Blendshape rig 构建(§3.6)— 四步

**Step 1 人脸网格融合(§3.6.1)**:拟合模板位置经 UV 对应传到高质量动画拓扑 → 再投影回输入几何;眼区按虚拟眼球中心(眼睑顶点 Procrustes 对齐求出)内嵌,保证闭眼不自交;对原 mesh 做**凸包减法布尔**切掉旧脸,模板边界顶点与剩余网格**最近点焊接**,小边塌陷清退化多边形。局部操作,保留发型/身份/非脸几何。

**Step 2 口腔构建(§3.6.2)**:VLM 选口腔原型(Table 6):

| 原型 | 目标 |
|---|---|
| Human | 真人/人形 |
| Canine | 长吻动物 |
| Monster | 非标牙齿的幻想生物 |
| Flat | 口腔极简/缺失的角色 |

牙齿模板经 **RBF 形变 + 带非均匀缩放的刚体变换**贴合嘴腔;**ARAP 形变**做初始摆放,再用 **SDF 迭代精修**:牙齿几何凸包转 SDF,与牙齿体积相交的脸面顶点沿 SDF 梯度平滑外推。牙龈舌头同步拟合并连接口腔内表面。ARAP+SDF 保证静息态和表情激活态都无牙齿-脸穿插。

**Step 3 UV/贴图迁移(§3.6.3)**:自动化 UV layout 求解器重打包(无重叠 + 足够 padding 防 mipmap 接缝);脸区 texel 密度 ≈ 非脸区 **10×**;口腔面放**独立贴图通道**;原贴图按「输出像素 → 合并 mesh UV 的重心坐标 + 图元 ID → 世界坐标 → 原 mesh 最近点 → 原 UV 采样」的向量化流程重采样。

**Step 4 FACS 转移与后处理(§3.6.4)**:从规范 FACS 模板向合并网格做**稀疏变形迁移**(Sumner & Popović 2004,三角形级仿射),用 **Point Deform + Delta Mush** 平滑融入相邻非模板区;再套表情特化后处理(Table 7):

| 形状类 | 精修 |
|---|---|
| 闭眼 | 上眼睑顶点贴下眼睑 + 局部松弛(接触感知闭合) |
| 眼凝视 | 眼区顶点绕虚拟眼球中心旋转 |
| 下颌相关 | 下牙子集随下颌整体开合运动 |
| 碰撞精修 | 每个表情形状重跑 SDF 牙齿-脸穿透检查 |

**形状分档**:Core **13** / Additional **46** / **Full 155**。

## 4. 数据集 Omni-Bench(§2)

- **1,000 个双足 T-pose 角色**:500 人/人形(13 职业 + 奇幻/科幻/赛博朋克人形)+ 500 动物(猫 150 ×10 品种、狗 150 ×10 品种、其他 200:熊/鼠/虎/狮/狐/狼/兔/鹿),最多 12 种外观变体。
- 初始静态 mesh 由 **AssetGen2 变体**生成;发布资产经过 riggability 初筛 → OmniFaceRig 处理 → 带 rig 输出。
- 每资产带完整生成链路数据:**文本 prompt + 2D 参考图 + 最终 mesh**(对 text-to-3D 研究有用)。
- 论文页面当时标 **Coming Soon** —— 数据是否已开放需要确认。

## 5. 实验数字(§4)

- 硬件:推理全部**单张 A100**;分割微调是离线训练(8×A100)。
- **Table 8**(200 个人/人形头,单位球归一化):

| 方法 | MAE↓ (mm) | Q95↓ (mm) | 穿透率↓ (%) |
|---|---|---|---|
| DT* | 2.93 | 8.41 | – |
| NFR | 2.77 | 7.21 | – |
| RigAnyFace | 1.01 | 2.94 | 0.17 |
| **OmniFaceRig** | **0.85** | **2.50** | **0.05** |

- **Table 9**(Omni-Bench 300 人+人形子集):OmniFaceRig MAE 0.92 / Q95 2.71 / 穿透 0.08 / **成功率 99.0%**(DT 82.4%,NFR 85.1%)。全 Omni-Bench 含动物:**零崩溃**。
- **延迟**:端到端 **20–30 s/资产**(含 I/O);Stage 1(评估+解析+关键点+配准)8–10 s,Stage 2(融合+口腔+UV+转移)10–15 s,I/O 占 10–15 s。
- 对齐质量 > RigAnyFace 16%/15%,穿透率好 3.4×。

## 6. 局限(§6,图 7)

- 只支持 human/long-muzzle/short-muzzle 模板族内的可见脸角色;**鸟喙、鱼脸、昆虫复眼、海马状长吻**等会被拒或拟合失败。
- 离线/批处理定位,不适实时交互编辑。
- 新拓扑族需要新模板 + 新分割标签 + 新 riggability 判据。

## 7. ⚠️ 论文 vs Challenge 交付物的 Gap(复现最关键)

| Challenge 要求 | 论文有什么 | Gap / 需要补的 |
|---|---|---|
| **输入是一张图**(图→glb) | 输入是**静态 3D mesh** | 需前置 image-to-3D 生成阶段(AssetGen2 不公开;候选:SF3D / Trellis / TripoSR / Meshy 等),或直接使用官方发的 T-pose 角色图→mesh 的现成链路 |
| 带**运动骨骼**的 glb | 只做**面部** rig,无身体骨骼 | body skeleton 不在论文范围;需身体 auto-rig(Mixamo / Anymate 基线 / 或 AssetGen 自带骨骼) |
| **ARKit 52 blendshapes** 全集 | FACS **155**(Core 13 / Additional 46 / Full 155) | 两套命名体系不同,需 FACS→ARKit52 映射或直接按 ARKit52 制作/重定向 |
| **中英音频口型同步** | **完全没有**音频驱动模块 | 需另加 speech→blendshape 的 lip-sync 方案(见 §8) |
| 牙齿与口腔内部定位正确 | ✅ ARAP+SDF(§3.6.2)+ 穿透率 0.05% | 直接对应,重点复现对象 |
| 面部表情无破损 | ✅ 三角翻转惩罚 + 碰撞精修 | 直接对应 |
| glb 输出 | 论文未定义输出格式 | 需 glTF 导出:morph targets(blendshapes)+ skinning(骨骼)+ KHR 扩展 |

## 8. 可复用开源组件(初步盘点,待逐一调研验证)

- **图像→3D**:SF3D(开源)、Trellis(开源)、TripoSR(开源)、Meshy API(商业)
- **2D 人脸解析**:face-alignment / MediaPipe / RetinaFace(68 点 landmark);SAM 2(开源,Meta);SAM 3 需确认是否开源
- **骨干**:Sapiens-1B(Meta 已开源 checkpoint,HuggingFace)
- **3D 人脸模板**:FLAME(开源,含眼睛/牙齿)、ICT FaceKit(不可商用?)
- **几何算法**:libigl(ARAP、布尔、凸包)、trimesh、xatlas(UV 打包)、CGAL(布尔/SDF)
- **变形迁移**:Deformation Transfer 开源实现(3D-Coded / pytorch 复现)
- **Delta Mush / Point Deform**:Maya 概念,需自己实现或找等效平滑
- **ARKit52**:Apple 官方 52 个 blendshape 命名清单
- **口型同步(中英)**:
  - 英文:Rhubarb Lip Sync(开源,音素→口型)、Wav2Lip(2D)
  - 3D/通用:MeshTalk、Audio2Face(英伟达,有 API/NIM)、FaceFormer 系
  - 中文:需确认音素/视素映射方案(候选:自训或商业 TTS+viseme 输出)
- **glTF 导出**:trimesh / pygltflib / Blender bpy

## 9. 复现路线图(建议)

1. **定输入链路**:确认官方资源的 2D 图 + glb 用法;选定 image-to-3D 前端(优先开源:SF3D/Trellis)。
2. **Stage 1 最小闭环**:渲染 → landmark + SAM2 分割 → 关键点(2D+射线反投影)→ 模板配准(式1/式2,用 libigl/自实现能量最小化)。
3. **Stage 2 最小闭环**:脸融合(凸包布尔+焊接)→ 口腔(牙齿模板 + ARAP + SDF)→ 稀疏变形迁移 → 输出带 morph targets 的 glb。
4. **补齐交付物**:body skeleton auto-rig;FACS→ARKit52 映射;中英 lip-sync 模块;A100 上部署可预览服务。
5. **验收自测**:表情无破损(翻面/自交检查)、牙齿穿透率、52 shapes 全集、中英音频对齐。
